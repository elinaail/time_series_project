### Эксперимент по моделированию сезонности
В рамках данного проекта необходим выяснить - "Как лучше всего моделировать сезонность?"

### Команда Проекта

**Гипотеза**

Добавление явных признаков сезонности (сезонные лаги, календарные переменные, члены ряда Фурье) улучшит точность прогноза глобальной модели CatBoost по сравнению с использованием только обычных лагов. Ожидается, что выигрыш будет больше для рядов с более сильной недельной сезонностью и будет снижаться при увеличении горизонта прогнозирования

---

## Данные

- **Датасет**: 
    - [M4 Daily dataset (Makridakis Competitions)](https://forecastingdata.org/)
- **Всего временных рядов**: 
    - 4 227 ежедневных временных ряда (финансовые, макро, микро, демографические, промышленные)
- **Выборка для проверки гипотезы**: 
    - 150 рядов, случайно отобранных из 2 745 рядов, удовлетворяющих условиям задания:
        - Минимальная длина ≥ 700 наблюдений
        - Сила недельной сезонности `|ACF(lag=7)| ≥ 0.20`
- **Сезонный период**: 
    - 7 дней (недельный)
- **Горизонты прогноза**: 
    - Оценка производилась на разных  горихонтах прогнозирования: следующей `(H = 7)` и второй неделе `(H = 14 дней)`
- **Алгоритм валидации**: 
    - Последние H наблюдений каждого ряда отложены как тест, оставшиеся используются для обучения

### Модели

**Бейзлайны (локальные, для каждого ряда отдельно)**

| Модель | Описание |
|---|---|
| `Naive` | Повторяет последнее наблюдение для всех h шагов |
| `SeasonalNaive` | Повторяет последний полный сезонный период (7 дней) |
| `AutoETS` | Экспоненциальное сглаживание, выбранное по AIC через statsforecast |
| `AutoTheta` | Метод Theta с автовыбором через statsforecast |

**CatBoost на различных признаках (глобальная модель на 150 рядах)**

| Вариант | Признаки |
|---|---|
| `lags_only` | лаги 1–6 (6 признаков) |
| `lags_seasonal` | лаги 1–6 + лаги 7,14,21,28 (10 признаков) |
| `lags_calendar` | лаги 1–6 + день недели, день месяца, месяц, номер недели, квартал (11 признаков) |
| `lags_fourier` | лаги 1–6 + пары sin/cos Фурье для period=7 (K=3) и period=365 (K=5) (22 признака) |
| `lags_seasonal_calendar` | лаги 1–6 + сезонные лаги + календарь (15 признаков) |
| `lags_seasonal_fourier` | лаги 1–6 + сезонные лаги + Фурье (26 признаков) |
| `all_features` | всё вышеперечисленное вместе (31 признак) |

**Важно**: 

M4 Daily преимущественно содержит финансовые (трендовые) ряды, близкие к случайному блужданию. Глобальная модель, обученная на сырых уровнях цен, работает плохо, поскольку информация об уровне не переносится между рядами. Обучение в пространстве первых разностей (`dy[t] = y[t] − y[t-1]`) убирает тренд и позволяет кросс-рядовое обучение. Разности дополнительно нормируются на среднее абсолютное отклонение (MAD) каждого ряда для выравнивания гетерогенной волатильности Прогнозы восстанавливаются в исходный масштаб через накопленную сумму по правилу:

$$\hat{y}_{T+h} = y_T + \text{MAD} \cdot \sum_{i=1}^{h} \widehat{dy}_{T+i}$$

где:
- $dy[t] = (y[t] - y[t-1]) / \text{MAD}$ — нормированные первые разности
- $y_T$ — последнее наблюдение из обучающей выборки,
- $\widehat{dy}_{T+i}$ — предсказанная разность на шаге $i$

### Результаты экспериментов

Метрики были усреднены по 150 рядам:

| Модель | MASE@H7 | MASE@H14 |
|---|---|---|
| `CatBoost lags_calendar` | **0.9532** | **1.3790** |
| `CatBoost lags_seasonal_calendar` | 0.9584 | 1.3822 |
| `CatBoost all_features` | 0.9612 | 1.3889 |
| `AutoTheta` | 0.9908 | 1.4392 |
| `Naive` | 0.9953 | 1.4488 |
| `CatBoost lags_only` | 0.9798 | 1.4152 |
| `SeasonalNaive` | 1.3517 | 1.7538 |
| `AutoETS` | 1.6379 | 2.0545 |

### Ключевые выводы

1. **Календарные признаки**
- Это наиболее полезная группа `(lags_calendar)`, так как `MASE=0.953` превосходит `lags_only (MASE 0.980)` на `2.7%` при `H=7`
- Кодирование дня недели фиксирует недельный паттерн независимо от лаговой структуры

2. **Сезонные лаги**
- Дают незначительный прирост при отдельном использовании, однако становятся частично избыточными при наличии календарных признаков

3. **Фурье признаки**
- Не дают особого преимущества в сравнении с признаками на лагах.

4. **СatBoost абсолютный лидер**
- Все варианты CatBoost модели превосходят бейзлайн решения на `0.2–5%` по `MASE` при `H=7`, что подтверждает способность глобальной кросс-рядовой модели извлекать значимые паттерны даже из трендовых финансовых данных — при условии удаления тренда через разностное преобразование.

5. **Влияние сезонности**
- Гипотеза о том, что более сезонные ряды выигрывают больше, не подтвердилась: в отфильтрованной выборке `(ACF(7) ≥ 0.2)` прирост `CatBoost` над `Naive` не зависит от силы сезонности и объясняется переносом паттернов между рядами.

6. **Горизонт прогнозирования**
- `MASE` ухудшается примерно на `50%` при переходе с `H=7` на `H=14` (CatBoost)
- Аналогично проиходит и для baseline решений `(Naive, AutoTheta)`
- Это подтверждает, что рекурсивное многошаговое прогнозирование накапливает ошибку на больших горизонтах прогнозирования

###  Конфигурация
Вышеперечисленные инсайты были получены, используя следующую конфигурацию проекта `config.py`:

```python
N_SAMPLE = 150           # количество рядов в выборке
RANDOM_SEED = 42         # воспроизводимость
SEASONAL_PERIOD = 7
TEST_HORIZONS = [7, 14]
MIN_LENGTH = 700
MIN_ACF = 0.20           # минимальный |ACF(7)| для включения в выборку

CATBOOST_PARAMS = dict(
    iterations=500,
    learning_rate=0.05,
    depth=6,
    loss_function="RMSE",
    early_stopping_rounds=50,
    random_seed=42,
)
```
